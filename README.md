📊 Vrinda Store Annual Sales Analysis – Excel Dashboard

📌 Project Overview

This project focuses on analyzing Vrinda Store's annual sales data for 2022 using Microsoft Excel. The dashboard provides insights into sales performance, order status, customer demographics, sales channels, and top-performing states.

The goal is to transform raw sales data into meaningful visual insights that can support better business decisions.

🎯 Project Objectives

- Analyze annual sales and order trends.
- Compare sales performance across different channels.
- Understand order status distribution.
- Analyze customer demographics by age and gender.
- Identify the top 5 states based on sales.
- Build an interactive dashboard using Excel.

🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning and Data Analysis
- Pivot Tables and Pivot Charts
- Slicers and Interactive Filtering
- Dashboard Design and Data Visualization

📈 Dashboard Insights

The dashboard highlights the following business metrics:

- Orders vs Channels: Compares order distribution across sales channels such as Amazon, Flipkart, Myntra, and others.
- Sales vs Orders: Tracks monthly sales and order trends.
- Top 5 States: Identifies the leading states based on sales.
- Order Status: Displays the distribution of delivered, cancelled, returned, and refunded orders.
- Orders: Age vs Gender: Compares customer order patterns across age groups and genders.
- Men vs Women: Shows the gender-wise distribution of orders.
